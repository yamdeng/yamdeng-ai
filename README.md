# yamdeng-ai

이 저장소는 **여러 AI 코딩 엔진이 동일한 마크다운 문서를 바라보도록** 두어, 저장소 기준으로 **분석·가이드라인·역할 정의가 서로 다르지 않게** 맞추기 위한 공간입니다.

## 목적

- **단일 출처(Single source of truth)**: 규칙·컨벤션·워크플로는 GitHub에 있는 MD 파일에 두고, 엔진마다 따로 두지 않습니다.
- **엔진 간 일관성**: Cursor, Copilot, 기타 도구 등 **서로 다른 엔진**이 있어도, 같은 파일을 읽게 하면 동일한 맥락으로 작업할 수 있습니다.
- **엔트리 정렬**: 각 도구는 자체 폴더·설정의 “엔트리 MD”를 쓸 수 있지만, **프로젝트 전역 기준은 `AGENTS.md`**를 따릅니다. 엔트리 파일은 가능하면 이 저장소의 내용과 동기화하거나 여기를 가리키는 방식을 권장합니다.

## 어떻게 쓰나요

1. 이 저장소를 클론하거나 서브모듈·심볼릭 링크 등으로 **각 엔진이 접근하는 작업 트리**에 둡니다.
2. 어떤 도구로 열든 **먼저 `AGENTS.md`를 읽고** 역할·우선순위·금지 사항을 맞춥니다.
3. 규칙을 바꿀 때는 **이 repo의 MD만 수정**하고, 도구별 복사본이 있다면 같은 변경을 반영합니다.

## 파일 안내

| 파일 | 역할 |
|------|------|
| `AGENTS.md` | 에이전트·보조 AI가 이 프로젝트에서 따라야 할 **공통 분석·행동 기준** (엔트리 MD들의 정렬 기준) |
